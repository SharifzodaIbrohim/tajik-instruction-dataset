# Формати маълумот (Data Format)

## Структураи асосӣ

Ҳар як файли JSON массиви объектҳо аст:

```json
[
  {
    "instruction": "матни дархост / савол",
    "input": "",
    "output": "ҷавоби табиӣ"
  },
  ...
]
```

### Майдонҳо

| Майдон       | Тавсиф                                      | Ҳатмӣ |
|--------------|---------------------------------------------|-------|
| `instruction`| Савол, дархост ё вазифаи корбар             | Ҳа    |
| `input`      | Контексти иловагӣ (ҳоло одатан холӣ)        | Не    |
| `output`     | Ҷавоби мувофиқ, табиӣ ва фоиданок           | Ҳа    |

## Мавзӯъҳои маъмул

- Нархҳо ва бозорҳо
- Маслиҳатҳои оилавӣ ва кӯдакон
- Тиб ва саломатӣ
- Тиҷорат ва кор
- Сайёҳӣ ва роҳ
- Анъанаҳо (Наврӯз, Рамазон ва ғ.)
- Ҳаёти ҳамарӯза
