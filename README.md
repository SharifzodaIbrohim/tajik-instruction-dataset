# 🇹🇯 Database — Базаи додаҳои калимаҳо ва корпуси забони тоҷикӣ

**Лоиҳаи васеъкунӣ ва омодасозии базаи додаҳои калимаҳои тоҷикӣ**

Ин репозиторий барои ҷамъоварӣ, тозакунӣ, васеъкунӣ ва омодасозии корпуси забони тоҷикӣ (калимаҳо, ҷумлаҳо, гуфтугӯҳои ҳамарӯза) сохта шудааст. Мақсад — ғанӣ кардани захираҳои забони тоҷикӣ барои омӯзиши моделҳои ҳуши маснӯӣ (мисли TajikGPT), таҳқиқоти забоншиносӣ ва корҳои NLP.

---

## 🎯 Мақсади лоиҳа

- Ҷамъоварии миқдори зиёди мисолҳои гуфтугӯӣ ва матнҳои тоҷикӣ
- Васеъкунии луғат (калимаҳо, ибораҳо, истилоҳот)
- Омодасозии маълумот дар формати `instruction` / `input` / `output` барои омӯзиши моделҳо
- Тозакунӣ, нормализатсия ва версиябандии датасетҳо
